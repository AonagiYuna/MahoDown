# MahoDown 测试清单

对照当前安装包逐项勾选。版本号以窗口「关于 / 设置 → 通用」或欢迎页小字为准。

## 0. 安装与启动

- [ ] 安装 `MahoDown_*_x64-setup.exe`，开始菜单能打开
- [ ] 欢迎页尺寸正常（不是一闪再放大）
- [ ] 用资源管理器「打开方式」打开 `.md`，直接进入编辑器大窗，不闪欢迎小窗
- [ ] 未保存关闭会提示；保存后标题与最近文档更新

## 1. 三种编辑模式

- [ ] 源码 / 分屏 / 富文本可切换，内容不丢
- [ ] 富文本：标题、列表、代码块、粗斜体显示正常
- [ ] 分屏：左侧改字，右侧预览跟着变
- [ ] 源码：行号、语法高亮、Tab 缩进

## 2. 查找 / 替换

- [ ] `Ctrl+F` 打开查找条（不是浏览器查找）
- [ ] `Ctrl+H` 打开替换；`F3` / `Shift+F3` 下一个 / 上一个
- [ ] 替换当前、全部替换；大小写开关
- [ ] `Esc` 关闭；源码 / 分屏 / 富文本都能用
- [ ] 版本历史是 `Ctrl+Shift+H`，不再占用 `Ctrl+H`

## 3. 大纲

- [ ] 左侧大纲列出文中标题（含加粗 / 链接标题）
- [ ] 点击任意标题，正文滚到对应位置（富文本尤其要测）
- [ ] 重复标题名也能跳到正确的那一条

## 4. 图片

- [ ] 粘贴剪贴板图片，插入 Markdown
- [ ] 拖入图片文件
- [ ] 默认本地相对路径 `./img/...`，保存后能再次打开显示
- [ ] 图床（若已配置）：上传成功或失败有提示，失败可保留本地

## 5. 导出与打印

- [ ] 导出 HTML 能打开
- [ ] 导出 Word（.docx）标题 / 列表还在
- [ ] 打印 / PDF 预览页能出

## 6. 版本历史

- [ ] 手动保存快照
- [ ] 自动快照（设置里间隔 > 0，等一轮）
- [ ] 对比、恢复后内容正确，恢复后仍需保存到磁盘

## 7. AI（需配置兼容接口）

- [ ] 设置里保存 Base URL / 模型 / Key
- [ ] 侧栏对话能改文稿；润色 / 续写 / 翻译有结果或明确报错
- [ ] Key 不出现在文档或日志明文里

## 8. 更新

- [ ] 「检查更新」弹出对话框，展示 **当前版本** 与 **最新版本**
- [ ] 已是最新：提示已是最新，没有「立即更新」
- [ ] 有新版本：可点「立即更新」，下载安装包并拉起安装程序，应用随后退出
- [ ] 版本比较正确（例如 0.1.9 < 0.1.10，不会把旧版当新版）

## 9. 外观与窗口

- [ ] 主题：系统 / 浅 / 深，菜单里切换不必关掉菜单
- [ ] `Ctrl+E` 专注模式隐藏大纲与状态栏，再按退出
- [ ] 最大化 / 还原图标正确；无边框窗口可拖动、缩放

## 10. 快捷键抽查

| 键 | 期望 |
|----|------|
| `Ctrl+N` / `O` / `S` | 新建 / 打开 / 保存 |
| `Ctrl+K` | 命令面板 |
| `Ctrl+,` | 设置 |
| `Ctrl+P` | 打印 |
| `Esc` | 关掉当前面板 |

失败时记下：版本号、模式（源码/分屏/富文本）、是否打开文件、复现步骤。
